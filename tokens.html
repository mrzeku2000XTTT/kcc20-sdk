To improve your own wallet: implement the same surface — Connect on click, silent reads after the popup closes, buyKron as a wallet-built TRADE, signPskt P2PK-only with global tx.inputs[] indexes, pushTx returns { txId, node }.

const bag = await kcc.getTokenBalance('KKDAG');
