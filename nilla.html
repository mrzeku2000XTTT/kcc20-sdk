Prepare

You build unsigned rusty-kaspa Safe JSON from pubkey + UTXOs + KRON quote. KCC20 does not pick the route.

The wallet-owned P2PK funding input must include utxo: { amount, scriptPublicKey, address }. Missing utxo → wrong sighash → false stack even on the right index.

signPskt — index is GLOBAL

await kcc.signPskt({ txJsonString, options: { signInputs: [{ index: G, sighashType: 1 }] } }) → string

index = tx.inputs[i] slot, 0-based. Not “0 = first wallet input.” Not KasWare-demo “sign 0 and 1.”

Typical KRON buy: 0 curve, 1 inventory, last = P2PK funding. So G is usually n-1, not 0. Confirm from your unsigned tx.

Return is a string. Broadcast that string. Do not parse + stringify (mutates scripts).

Reject → User rejected. Stop. No retry loop.

Broadcast

await kcc.pushTx(signedString) → { txId, node }

Or your own node. Do not double-broadcast. Do not push the failed blob again.

false stack entry at end of script execution

CHECKSIG pushed 0. Most likely: signInputs listed global 0 (curve) or 0,1 (curve + inventory). SCORPION v166 then wrote a P2PK signature over the covenant redeem. Node verified false.

Smallest fix: next Sign, list only connected-address P2PK funding indexes, sighashType: 1. Hard-refresh PWA to BUILD 167. Do not rebroadcast the old signed JSON.

10-point check (no tx bodies, no secrets)

  1. Total input count unsigned vs signed (must match).
  2. Each global index role: curve / inventory / P2PK funding (from SPK prefix, not printed scripts).
  3. Exact signInputs indexes you passed.
  4. Every entry sighashType: 1.
  5. Per input: did signatureScript change? byte length before/after. Never print hex.
  6. Covenant scripts unchanged. If they changed, you listed those indexes — that is the failure.
  7. P2PK funding: empty before, ≥65 bytes after.
  8. Broadcast string is the exact SCORPION return (same length).
  9. Treat index as global. [0] from KasWare demos is wrong for KRON.
  10. Next Sign: signInputs: G.map(i => ({ index: i, sighashType: 1 })) where G is only P2PK funding slots.
