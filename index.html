Connect KCC20 Wallet in any app

One script. Creates window.kcc20. Same job as KasWare’s window.kasware, except this is a hosted PWA — no Chrome extension. Keys never leave the wallet. Your app builds the unsigned transaction. The user Approves in our window.

Install the SDK Open live demo

Install

Only call Connect from a user click. Never on page load. Never on app switch.

<script src="https://kcc-20-wallet.vercel.app/sdk.js?v=166"></script>

Or from this docs site / jsDelivr (still opens the live PWA):

<script src="https://cdn.jsdelivr.net/gh/mrzeku2000XTTT/kcc20-sdk@main/sdk.js"></script>
After load: window.kcc20.sdkVersion === "166" and window.kcc20.origin === "https://kcc-20-wallet.vercel.app"

Quick start

const kcc = window.kcc20;

// POPUP — user taps Connect, Approves, popup CLOSES. That close is required.
const accounts = await kcc.connect();
const address = accounts[0];                 // kaspa:q…

// SILENT — popup stays closed. Do not connect() again.
const network = await kcc.getNetwork();      // kaspa_mainnet | kaspa_testnet_10
const pubKey  = await kcc.getPublicKey();    // hex
const utxos   = await kcc.getUtxoEntries(address);

// YOU build unsigned rusty-kaspa Safe JSON from pubKey + utxos + your route.

// POPUP — user Signs
const signed = await kcc.signPskt({
  txJsonString: unsignedSafeJson,
  options: { signInputs: userP2pkIndexes.map(i => ({ index: i, sighashType: 1 })) }
});

const { txId } = await kcc.pushTx(signed);   // optional
If getPublicKey / getUtxoEntries throw Connect KCC20 Wallet first after a successful Connect, you are on a stale SDK. Load sdk.js?v=166, hard-reload, Connect once more.

API reference

connect() / requestAccounts()

Returns Promise<string[]> of kaspa:q… addresses. Opens the PWA. User must already have created or imported a key and unlocked with PIN. Allow popups for your origin.

Account reads (silent after Connect)

MethodReturns
getAccounts()same addresses, no extra prompt
getNetwork()kaspa_mainnet or kaspa_testnet_10. KIP-12 normalizes to mainnet / testnet-10
getPublicKey()hex public key from the Connect snapshot
getUtxoEntries(address?)UTXOs. REST fields (outpoint, utxoEntry) and KasWare-flat aliases
getBalance(address?){ confirmed, unconfirmed, address } sompi
getHoldings() / getTokenBalance(tick)KAS + KCC20 bags

signPskt / pushTx

You pass unsigned rusty-kaspa Safe JSON. We return a signed string.

const signed = await kcc.signPskt({
  txJsonString,
  options: { signInputs: [{ index: 0, sighashType: 1 }] }
});
const { txId } = await kcc.pushTx(signed);

signInputs: only this wallet’s P2PK input indexes, sighashType: 1 (SIGHASH_ALL). Never list covenant / KRON curve / pool / token-cell inputs. Reject → error User rejected.

sendToken({ tick, amount, dest })

Wallet-built KCC20 send (TTT Fund). Not a KRON curve buy — those you build, then signPskt.

Events

kcc.on('accountsChanged', (accounts) => {});
kcc.on('networkChanged', (network) => {});
kcc.on('disconnect', () => {});

disconnect() forgets this origin. The popup closes. Stay on your tab.

If a real KasWare extension is present, do not overwrite window.kasware. Offer both adapters. SCORPION uses window.kcc20 only.

window.addEventListener('kaspa:provider', (ev) => {
  const { info, provider } = ev.detail || {};
  // info.rdns === 'app.kcc20.wallet'  → KCC20 PWA
});
window.dispatchEvent(new Event('kaspa:requestProvider'));

Load sdk.js before you dispatch kaspa:requestProvider.

Pitfalls

  1. Stale SDK — require sdkVersion === "166". Use ?v=166 on the script URL.
  2. Connect first after Connect — old SDK needed the popup to stay open. v166 keeps the session. Do not Connect-loop.
  3. Wrong object — call reads on the same window.kcc20 that ran connect().
  4. Empty UTXOs — that address has no KAS. User must fund it.
  5. Network strings — normalize /testnet/ → testnet-10.
  6. signInputs — only P2PK of the connected address.
  7. Popup blocked on Sign — Sign needs a user click (or the same click as Prepare).
  8. sendToken ≠ curve buy — sendToken transfers a KCC20 bag. A KRON purchase is a tx you build, then signPskt.
  9. Eager script load — load sdk.js on Connect click, not on every page mount.

Safety

  • You build. They sign. Never send a private key or PIN.
  • Never invent amounts. Never credit a user without a real txId.
  • SIGHASH_ALL (1) only on this build.
